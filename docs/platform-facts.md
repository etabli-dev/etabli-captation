# Platform facts

Every OS/OBS/app-specific identifier the code relies on has exactly one PF entry here.
Code that hard-codes such an identifier carries a `# PF-xxx` comment. `tools/check_facts.py`
enforces both rules. Columns: PF-ID, status (`verified`, `pending`, `superseded`, `refuted`),
OS, OS version, OBS/websocket version, app and version, the fact, the evidence (command → output
excerpt) and the date. A `refuted` or `superseded` entry stays in the table with a pointer to its
replacement, so older reports remain interpretable. A new OBS major version re-opens the
OBS-scoped facts of that OS.

ID ranges: Linux PF-001…099, macOS PF-101…199, Windows PF-201…299. Status `pending` (ADR-015)
marks a fact prepared on Linux for another OS: the code may reference it, but
`tools/check_facts.py` fails on that OS (and with `--release`) until the entry is re-checked
there and set to `verified` (or `refuted` with a replacement).
